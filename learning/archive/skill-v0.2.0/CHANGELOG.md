# Changelog

## 0.2.0 — 2026-09-29

- 将教学原则改成有输入条件、动作与等待位置的回合规则，覆盖继续/改好了/提示等短回复。
- 增加项目 AGENTS.md 学习触发约定；补充按任务区分的轻量接续记录。
- 明确初学者示范、提示递减、独立检验与迁移；保留一步一改、架构表达和阶段面试偏好。
- 区分工程测试与用户掌握，同日练习合并；旧计数保留，首次新评估校准成功链，不伪造历史。
- 复习默认逐题、及时纠错、跨日升档；概念与错题按实际检验结果同步。
- 增加研究依据及行为验收案例；修复空字段跨行解析、转义管道解析与坏行静默丢弃。

原因：用户报告未稳定遵守辅导方式；记录显示同日高频计数与代码测试作为掌握证据的风险。此版本提升规则可执行性，效果待真实学习回合验证。

兼容性：原学习表结构/ID/历史数值保留；增加接续段和计数解释。原 0.1.0 Skill 保存于 learning/archive/skill-v0.1.0/ 供回滚。

## 0.1.0 — 2026-09-19

- 创建仅限当前项目的 `learning-coach` Skill。
- 建立项目驱动教学、提示阶梯、主动回忆、错题去重和证据化掌握状态。
- 建立可调整的间隔复习规则与 3–5 题复习模式。
- 增加 Markdown 学习状态、复习队列生成、状态校验和保守归档工具。
- 增加 Skill Maintenance Mode、语义化版本和向后兼容要求。

原因：把零散学习问答升级为可长期迭代、可审计且不依赖数据库的个人学习系统。
