# 主动回忆与复习排期

## 选题

先读队列、错题、概念、进度；日期文案过期时重建。默认一组 3–5 题逐题问，时间少时 1–2 题。无历史则说明并做起点诊断，不编造“昨天学过”。

到期内容中先选弱项/重复误区，再选最久未复习项；概念和关联错题合为一个练习块，避免占满一组。未来项不压过到期项；对比容易混淆的已学机制，不随机混入未学内容。

内部读答案用于判分，用户作答前不展示概念摘要、错题纠正或答案。可以提供任务必需代码/参数。请求提示后转引导练习，及时纠正误解。

## 首次尝试质量

出题与判分先执行 assessment.md。生产设计按目标和约束评估，不能按 Demo 的现有实现判错。题目本身有歧义时记“无法判分”，不赋 0 分或追加错题。

| 分数 | 证据 |
|---|---|
| 5 | 独立正确，能迁移或说明边界 |
| 4 | 独立正确且理由成立，仅非关键遗漏 |
| 3 | 轻提示后正确，或核心正确但因果不全 |
| 2 | 部分正确，需明显提示 |
| 1 | 错误，反馈后能识别 |
| 0 | 已学内容无法回忆或核心模型错误 |

未答、超纲、测试通过、看示范后说懂了均不评分。迟疑/措辞生涩本身不扣分。首答错后重试成功记“首答 1，纠正后完成”，不能改写为独立 5 分。

## 跨日规则（工程启发式）

阶梯 `1 → 3 → 7 → 14 → 30 → 60 → 90` 天是默认约定，研究并未证明这组天数普适；按遗忘、目标日期和负担调整。

- 初次练习排次日复习；同日重试可纠错，不连续升档。
- 到期且跨日独立回忆 4–5：成功链 +1、间隔升一档；旧间隔不在阶梯上取下一更大档。最多每天升一档。
- 3：成功链清零，通常 1–3 天；当场再解释不算额外成功。
- 0–2：成功链清零，通常次日复习；当下先纠错，稍后变式检查。
- 提前独立成功：记应用证据，默认保留原日期；提前失败可缩短到次日。
- 逾期未答不算失败，保留原日期和状态；实际复习后从实际日期算新日期。
- 新的独立尝试重犯同根因：repeat_count +1、优先级提高一级（最高 critical）；同一反馈链不反复计数。

概念与错题同轮被实际检验时同步更新两处证据/日期；只答对概念定义不能关闭所有关联错题。首次独立纠正可转 monitoring，跨日变式再通过才可 resolved，仍需检查可保留 next_review。

状态门槛与计数兼容见 state-model.md；旧高计数不得直接作为 mastered 依据。
