# 主动回忆与间隔复习

仅在复习、测验、掌握检查或安排复习时读取本文件。

## 选择题目

先运行或读取 `review_queue.md`，按以下优先级选择通常 3–5 题：

1. 已到期且来自重复错题或 `weak` 概念。
2. 已到期的普通概念。
3. 即将到期且与当前项目阶段相关的概念。
4. 为检查迁移而抽取的一个 `understood`/`mastered` 概念。

不要连续用同一措辞复述旧题。混合题型：自己的话解释、预测行为、找 bug、修改/补全代码、API 使用、设计权衡、实现比较、面试式追问。优先使用当前项目的小片段；避免泄露敏感代码或不必要的大段复制。

先展示问题，不展示答案。可以一次给 3–5 题，也可在需要根据前题自适应时逐题进行。

## 质量分

根据可观察表现记录 0–5：

- `5`：独立、准确，能解释原因并迁移到新情境。
- `4`：独立且基本准确，只有非关键遗漏。
- `3`：在轻微提示后正确，或答案正确但解释犹豫/不完整。
- `2`：部分正确，需要明显提示或仍有关键混淆。
- `1`：错误，但看到提示后能识别问题。
- `0`：无法回忆，或重复出现相同错误心智模型。

不要把自报“懂了”当作高质量证据。

## 间隔规则

基础阶梯为 `1 → 3 → 7 → 14 → 30 → 60 → 90` 天，但这是默认值，不是机械日历。

- 质量 `4–5`：`success_streak + 1`，进入下一档；若有强迁移证据，可多前进一档并在 notes 说明。
- 质量 `3`：连续成功清零或保守保持，间隔维持或缩短一档；通常不超过 7 天。
- 质量 `0–2`：`success_streak = 0`，状态通常为 `weak`，间隔回到 1 天；若只是可解释的轻微失误，可安排 1–3 天。
- 重复出现同一错题：增加 `repeat_count`、至少提高一级 priority，并安排 1 天内复习；在后续题中换情境验证根因。
- 能独立解释并正确修改项目代码，比单纯选择题答对更强；犹豫、模糊解释或靠提示应缩短间隔。

任何偏离基础阶梯的安排都应有简短证据理由。使用本地日期 `YYYY-MM-DD`，不要安排过去日期。

## 状态转换

- 首次学习后通常是 `learning`，不是 `understood`。
- 质量 `0–2` 或重复误区可转为 `weak`。
- 至少两次不同情境下质量 `4–5` 可转为 `understood`。
- 跨至少 14 天、至少三次质量 `4–5`，且有一次迁移或真实项目应用，才可转为 `mastered`。
- 一次失败不必把长期稳定的 `mastered` 直接降到 `weak`；可降为 `understood` 并缩短复习间隔，观察是否重复。

## 完成后

更新概念、已有错题和进度；必要时新增错题。然后运行：

```bash
python3 .agents/skills/learning-coach/scripts/update_review_queue.py
python3 .agents/skills/learning-coach/scripts/validate_learning_state.py
```

对用户只给简短、证据化的结果：哪些已稳定、哪个误区仍在、下一次复习重点。不要输出冗长成绩报告。
