直接打开 [开始学习](site/index.html)，或双击本目录下的 `开始学习.html`。阅读无需安装软件、无需联网、无需API Key。移动或发送时请保留整个目录，不能只复制一个HTML文件。

- **109篇完整原文HTML**：逐篇转换仓库Markdown，保留标题、表格、示例、图片和文档间链接。
- **486道问答及参考解**：108道新编课后/阶段题、156道源主题题、222道源公司主题题；另有52项实践变式答案。题数是条目数，主题可能重叠，不代表486个独立考点。
- **26个Python小实验**：标准库、无付费调用，含任务、完整程序、预期输出、解释和变式答案。实验仅验证机制，不伪装成真实模型/训练/压测。
- **26组双场景步骤回放、41张原始SVG、3个交互演示**：RAG适用性过滤、GraphRAG多跳、提交后崩溃恢复；每课原实验/边界两种场景，共52个；每帧同时标出对应讲解和真实代码行；每一步显示输入、处理、输出与状态快照，支持播放、暂停、倒退、调速和重置。首帧默认可见，无法播放时可展开全部步骤文字。
- 全文搜索、题目筛选、可折叠答案、作答区、自评复习安排、学习记录导出/导入、打印。
- 原仓库**174文件完整快照**、MIT许可、125条面经来源档案、文件覆盖清单及关键勘误。

## 怎么学

1. 先读每课原理。演示已移到对应讲解之后，不需要一上来猜动画在讲什么。
2. 跟随同一个案例：正文里的输入、变量和数字，会在演示与代码里继续使用。
3. 每步先看输入/输出，再读“为什么这样做”和真实代码片段；可以沿链接定位完整程序。
4. 紧接着运行同一份Python程序，对照预期输出；边界场景的替换行会明确标出。
5. 完成后面的变式题。每题标明对应概念，先自己回答，再展开参考解。
6. 如实记录自评并跨日复测；第26课使用真实项目证据做模拟面试。

最初的Agentic RAG/GraphRAG需求集中在第07—14课，先修不熟时回第01—06。第21课训练专题可作为进阶支线；应用岗位也可先完成22—26后返回。

## 相对路径与浏览器记录

所有站内导航、脚本、样式和图均为相对路径，不使用CDN或在线模型。外部一手资料链接需要联网，但不影响正文、答案和动画阅读。`source/`与`site/`保持同级，才可下载原文与看SVG。

自评、复习日期和作答保存在当前浏览器本地。浏览器对 `file://` 的localStorage规则可能不同；页面显示不可持久保存时，请导出JSON。即使没有该提示也建议定期导出。更换浏览器、路径、HTTP端口会产生独立记录；用导入功能迁移。导入会替换当前站点记录，页面会先确认。没有自动后台提醒，也不会把自评写成项目中的已掌握记录。

若浏览器对本地文件有特殊限制，可在本目录启动本地预览：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/site/index.html`。这是可选项；普通阅读不依赖服务器。
