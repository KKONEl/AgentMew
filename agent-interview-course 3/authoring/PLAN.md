# 离线 Agent 面试学习站

用户授权：把整个 agent-interview-hub 整理为多个相对路径 HTML 文件，循序渐进、详尽教学、课后题和 simple 实践，含答案。属于明确交付，不沿用上一轮只问一题的教学停止点。

## 交付设计
- 独立目录，不改现有代码和其他聊天学习状态，不提交或发布。
- 固定源快照 e5b92617455e5ecc105162a22a42796c3041162d，保留完整 174 文件、MIT 许可、来源与下载日期。
- source/ 原始文件；site/index.html 入口；site/lessons/ 按先修组织的课程；site/library/ 全部 Markdown 转 HTML；site/labs/ 标准库 Python 实践与参考解；authoring/ 可重建源。
- 阅读时无网络依赖、无 fetch、无构建要求；链接和图全为相对路径。外部资料链接明确是外部。
- 每课含目标与先修、具体场景、机制和边界、已解例、三题以上附答案、小实践含完整参考程序与预期输出、验收、教材映射。
- 主线：基础与控制流→工具/上下文→RAG→恢复/协作/评测安全→模型后端与项目面试。模型训练作为进阶分支。
- 搜索覆盖课程与原文；浏览器学习记录为自评，不写 concepts，不声称掌握。提供导入导出；file:// 存储不可用时提示。
- 事实校正单列，原文快照不改；岗位与面经标为历史汇编，课程不承诺录用。

## 执行顺序
1. 保存全库与文档清单，检查许可。
2. 各主题独立撰写教程和标准库小实验，主代理撰写 RAG 主线并构建静态页面。
3. 实现导航、搜索、答案折叠、自评复习、打印与源文映射。
4. 验证源文件覆盖、相对路径与锚点、HTML 转义、全部实验运行、页面桌面/窄屏和交互；生成压缩包。

## 验收重点
- 每份 Markdown 均有完整原文页；JSON/代码/图等保留本地下载。
- 中文空格路径、跨文档锚点、SVG 图片、代码块和答案可读。
- 搜索无网络，存储被禁用不崩溃，导入不注入 HTML。
- 每个实验是无密钥、无付费调用的机制演示，不假称真实 LLM 评测。
- 仓库材料的二手面经、示例代码、旧产品参数与一手事实明确区分。
