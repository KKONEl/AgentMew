89. 检索文档夹带越权指令时，为什么只强化系统提示词仍不够？

题目 ID：Q-e124f9a2179c · 编辑难度：hard

相关主题的报道公司（非逐题归属）：vivo

参考答案

注入把不受信材料伪装成控制指令，提示词只能降低风险，不能当作强制授权。需分隔数据与指令、收缩工具能力、执行时鉴权与审批、控制外发并对抗测试。

得分点

  • 检索结果没有系统权限
  • 把最坏行为限制在最小作用域

追问：模型仍被诱导时哪层负责阻断操作？

易错点：不能承诺某一句提示词能彻底防住注入。

面经主题线索：INT-4aea8e37ae（B：曾定位公开原帖）

答案机制资料：INJECTION：OWASP LLM01: Prompt Injection；MCPTOOLS：MCP tools

90. 执行模型生成代码时，沙箱应限制哪些资源和访问能力？

题目 ID：Q-684e7c1b76b2 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动、百度

参考答案

按风险隔离进程或更强沙箱，限制 CPU、内存、进程、磁盘、时间及网络出口；只暴露任务所需文件和短期凭据。记录执行物与结果，任务结束清理，更新沙箱组件。

得分点

  • 容器不等于绝对安全边界
  • 限制宿主挂载和特权

追问：恶意程序疯狂 fork 或向内网探测如何阻止？

易错点：代码通过静态检查仍不能代替运行时隔离。

面经主题线索：INT-2bfa666e65（B：曾定位公开原帖）；INT-15d1d6b299（B：曾定位公开原帖）

答案机制资料：SANDBOX：gVisor architecture guide；INJECTION：OWASP LLM01: Prompt Injection

91. 多租户共享运行平台时，模型调用和代码沙箱如何分别隔离？

题目 ID：Q-268ff8a24a12 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：小米

参考答案

模型网关按租户鉴权、配额、密钥和日志权限隔离；沙箱另管文件系统、进程、网络与资源池。所有产物、缓存及存储键均带租户作用域，阻止跨租户复用敏感状态。

得分点

  • 计算隔离与数据隔离分别测试
  • 共享池回收前验证清理

追问：复用一个热沙箱可能泄漏什么？

易错点：数据库隔离了，工作目录和缓存仍可能串租户。

面经主题线索：INT-91419e91fb（B：曾定位公开原帖）

答案机制资料：SANDBOX：gVisor architecture guide；MCPTOOLS：MCP tools

92. 意图识别准确率已有提升，仍如何避免高风险动作被误触发？

题目 ID：Q-fde3165e4e19 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：美团

参考答案

把“识别到意图”与“获准执行”分开：高风险操作校验对象和业务条件，展示结构化变更并二次确认，提交时检查审批范围与版本。用风险加权指标评估误触发，而非仅平均准确率。

得分点

  • 默认最小权限
  • 不可逆操作更严格

追问：确认界面与最终执行参数不同如何防止？

易错点：总体准确率提高不能证明危险误触发已可接受。

面经主题线索：INT-0f90bd85b5（C：仅聚合线索）

答案机制资料：MCPTOOLS：MCP tools；INTERRUPT：LangGraph interrupts and idempotent side effects

93. 人工审批放在规划、参数确认还是执行阶段，各有什么边界？

题目 ID：Q-a4cc7dccb56a · 编辑难度：hard

相关主题的报道公司（非逐题归属）：九方智投

参考答案

规划审批确认目的和边界，参数确认约束具体动作，执行前再校验主体权限、资源版本与有效期。越靠前越适合授权范围，越靠近提交越能防止参数与状态变化。

得分点

  • 审批绑定动作指纹
  • 变更后重批，支持撤销

追问：用户批准后 Agent 又改了一个参数怎么办？

易错点：一次模糊的“同意继续”不应授权所有后续高风险操作。

面经主题线索：INT-fef75911f3（C：仅聚合线索）

答案机制资料：INTERRUPT：LangGraph interrupts and idempotent side effects；MCPTOOLS：MCP tools

94. 高合规场景下，怎样验证模型没有绕过 Skill 约束执行操作？

题目 ID：Q-c82aec2c5e88 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：快手

参考答案

将必须遵守的规则编码为执行策略、状态机和权限检查，Skill 只提供指导。用越权工具、变更参数、跨租户、审批绕过和恢复重放的负向测试验证，并审计实际回执。

得分点

  • 覆盖所有执行入口
  • 说明未知风险与独立审核范围

追问：模型遵守了文字流程却调用了错误资源怎么办？

易错点：没有发现越权不是形式化安全证明。

面经主题线索：INT-bbcb367aed（B：曾定位公开原帖）

答案机制资料：INJECTION：OWASP LLM01: Prompt Injection；MCPTOOLS：MCP tools

95. 理赔 Agent 面对材料缺失、口径反复或金额矛盾时，何时必须转人工？

题目 ID：Q-2e3279463eb1 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：小米

参考答案

把理赔条件、材料要求与金额计算交给经审核的规则和权威系统；材料矛盾、身份不明、超权限或规则不能确定时暂停并转人工，保留证据和原结论版本。具体阈值由业务与合规确定。

得分点

  • 模型用于收集、解释和辅助
  • 不自行承诺拒赔或赔付

追问：用户改口后之前的结论怎样撤销？

易错点：本答案是工程设计，不是保险理赔规则或法律意见。

面经主题线索：INT-6c63a24bd2（B：曾定位公开原帖）

答案机制资料：MCPTOOLS：MCP tools

96. 金融业务发生错误执行后，怎样保留可用于追责的决策与执行证据？

题目 ID：Q-14148b7dd4a9 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：小米

参考答案

记录可信主体、授权/审批版本、输入来源、规则与模型版本、动作意图、参数摘要、资源版本、回执和时间；访问受控并使用防篡改存储策略。追责仍需组织流程及合规认定。

得分点

  • 脱敏、留存与删除按业务要求
  • 保留结果未知和人工介入

追问：只有模型说“批准了”，能当有效授权吗？

易错点：不能承诺普通日志或一个哈希就天然不可篡改。

面经主题线索：INT-6c63a24bd2（B：曾定位公开原帖）

答案机制资料：MCPTOOLS：MCP tools

97. 用户试图诱导系统泄露内部提示词时，如何设计测试并说明防护边界？

题目 ID：Q-87672c7f8b3d · 编辑难度：medium

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

覆盖直接索取、角色伪装、翻译编码、检索注入和多轮诱导；测是否泄露受保护内容或触发敏感工具。关键秘密不放入提示词，权限独立控制，报告剩余风险。

得分点

  • 测试拒答之外的工具行为
  • 对日志和检索也防泄漏

追问：提示词不可泄露是否应作为唯一防线？

易错点：无法把所有提示词当作可靠保密容器。

面经主题线索：INT-2bfa666e65（B：曾定位公开原帖）

答案机制资料：INJECTION：OWASP LLM01: Prompt Injection

98. 你会怎样证明一次工具操作可审计，而不只是日志里出现了工具名称？

题目 ID：Q-74a84fb57ccb · 编辑难度：hard

相关主题的报道公司（非逐题归属）：作业帮

参考答案

把动作提议、校验、审批、真实执行和结果提交分开记录，通过任务/操作 ID 及外部回执串联；证据可校验主体、参数和状态变化，并能回放或查询确认。

得分点

  • 处理重试、失败和未知结果
  • 敏感字段最小化保存

追问：日志显示成功但业务状态没变，信哪一个？

易错点：记录工具名称而无授权与业务回执不足以审计。

面经主题线索：INT-aa5fb6e122（C：仅聚合线索）

答案机制资料：MCPTOOLS：MCP tools；STATE：LangGraph persistence
