126. 手写二叉树按层遍历，并说明队列与每层结果的空间开销。

题目 ID：Q-b0fb9fd54eda · 编辑难度：medium

相关主题的报道公司（非逐题归属）：字节跳动、美团

参考答案

队列保存下一批待访问节点，每轮先记当前队列长度并只弹出该层，再把子节点加入。时间 O(n)，队列空间 O(最大层宽)，输出本身 O(n)。

得分点

  • 空树与偏斜树要覆盖
  • 代码函数 level_order

追问：为什么不能循环到队列为空才算一层？

易错点：共享可变 list 并追加引用可能让多层结果指向同一对象。

128. 只遍历一次链表时，如何删除倒数第 N 个节点并处理头节点边界？

题目 ID：Q-66e96969e944 · 编辑难度：medium

相关主题的报道公司（非逐题归属）：字节跳动、小红书

参考答案

加哑节点，让快指针先走 N 步，再同速移动快慢指针直到快指针到最后，删除慢指针后继。时间 O(n)，附加空间 O(1)，约定 N 非法时抛错。

得分点

  • 覆盖删除头/尾及空链表
  • 代码函数 remove_nth_from_end

追问：N 超过链表长度怎样报告？

易错点：不使用哑节点容易漏掉删除头节点。

129. 从不限次数到最多两次、再到最多 K 次交易，怎样统一设计股票买卖状态转移？

130. 实现两个区间集合的差集，说明相交、嵌套和端点边界约定。

131. 实现最长递增子序列，并比较动态规划与更低时间复杂度的方案。

  • 代码函数 lis_length

追问：最小结尾数组是否一定是一条真实子序列？

易错点：要返回具体序列还需维护前驱，不能直接返回 tails。

132. 数组可包含负数时，怎样求和等于 K 的最长连续子数组长度？

题目 ID：Q-fb97d7bc9514 · 编辑难度：medium

相关主题的报道公司（非逐题归属）：海康威视

参考答案

维护前缀和及每个前缀和最早出现的位置；当前和为 s 时查 s-K，更新最长距离。时间平均 O(n)、空间 O(n)，初始映射含0对应位置-1。

得分点

  • 最早位置不能被后出现覆盖
  • 代码函数 longest_subarray_sum_k

追问：若含负数，普通双指针为什么不可靠？

易错点：先覆盖旧前缀位置会错过最长解。

面经主题线索：INT-e363eb73e2（B：曾定位公开原帖）

答案机制资料：未单列外部机制资料，属于编辑推导，须结合具体契约独立验证。

133. 原地反转单链表，并用空链表和单节点说明边界处理。

题目 ID：Q-c2a7527de45a · 编辑难度：medium

相关主题的报道公司（非逐题归属）：快手

参考答案

迭代保存 next，再让当前节点指向 prev，随后前移两个指针。时间 O(n)、附加空间 O(1)，空链表返回 None，单节点保持不变；约定无环输入。

得分点

  • 改变链接前先保存后继
  • 代码函数 reverse_list

追问：要求不修改输入时如何处理？

易错点：先改 next 再找原后继，会丢失剩余链表。

面经主题线索：INT-bbcb367aed（B：曾定位公开原帖）

答案机制资料：未单列外部机制资料，属于编辑推导，须结合具体契约独立验证。

134. 求字符串中最长有效括号段的长度，并解释状态或栈的含义。

题目 ID：Q-ff0bd487d69b · 编辑难度：medium

相关主题的报道公司（非逐题归属）：阿里巴巴

参考答案

栈保存未匹配括号位置，初始放-1作起点；遇左括号压栈，右括号弹栈，栈空则记录新的分界，否则用当前位置减栈顶更新长度。时间 O(n)、空间 O(n)。

得分点

  • 输入限定括号字符
  • 代码函数 longest_valid_parentheses

追问：为什么需要一个无效起点哨兵？

易错点：统计左右括号总数无法处理合法区间被截断的问题。

面经主题线索：INT-39b8389f8f（B：曾定位公开原帖）
