49. 文档切块过大和过小分别会带来什么可观测问题？

题目 ID：Q-a8509ef76a1b · 编辑难度：medium

相关主题的报道公司（非逐题归属）：字节跳动、拼多多

参考答案

块过大会引入噪声、挤占上下文并稀释匹配信号；过小会切断定义、条件和指代。固定检索预算，对比分块方案的证据覆盖、排序质量、回答正确率与延迟。

得分点

  • 同时观察跨块证据丢失和重复召回
  • 不要只调 chunk size

追问：重叠比例变大是否一定更好？

易错点：不存在对所有文档都最优的固定长度。

面经主题线索：INT-1c8ef39841（B：曾定位公开原帖）；INT-a896abf415（C：仅聚合线索）

答案机制资料：BM25：Elasticsearch similarity settings: BM25

50. Markdown 没有标题时，请给出可执行的切块策略及评测办法。

题目 ID：Q-be81734af45d · 编辑难度：hard

相关主题的报道公司（非逐题归属）：美团

参考答案

先解析段落、列表、代码和表格边界，再按 token 上限组合；超长段按句子或有界窗口继续切，保留适当重叠和原文偏移。语义切分作为可比较的方案而非必选项。

得分点

  • 给块附文档版本和定位
  • 用真实查询与答案证据回归

追问：代码块或大表格超过上限怎么办？

易错点：不能因为没有标题就把整篇文档作为一个块。

面经主题线索：INT-49f4a7b7c0（B：曾定位公开原帖）

答案机制资料：BM25：Elasticsearch similarity settings: BM25

51. 对 PDF、纯文本和 Markdown，你会保留哪些结构元数据用于切分与检索？

题目 ID：Q-40d256b2923c · 编辑难度：medium

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

保留文档 ID、版本、章节路径、页码、文本/字符偏移、段落类型与访问权限；PDF 还应保存版面坐标及 OCR 映射。纯文本没有的结构不应伪造。

得分点

  • 解析顺序影响表格和多栏
  • 存原文及可回溯清洗映射

追问：解析器升级后旧引用如何保持稳定？

易错点：只保存清洗后的字符串会丢失可靠溯源位置。

面经主题线索：INT-1c8ef39841（B：曾定位公开原帖）

答案机制资料：未单列外部机制资料，属于编辑推导，须结合具体契约独立验证。

52. 按标题切块后大小极不均匀时，如何继续处理而不丢失章节语义？

题目 ID：Q-71b2bf676f03 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：九方智投

参考答案

小节可在不跨越语义边界的前提下合并；大节按段、句或结构元素再分，并把章节路径作为元数据或短前缀。检索时按需要扩展相邻块或父节。

得分点

  • 限制重复父标题开销
  • 用证据命中与上下文占用共同评测

追问：相邻块合并会不会混入无关内容？

易错点：按标题切完并不意味着无需再控制长度。

面经主题线索：INT-fef75911f3（C：仅聚合线索）

答案机制资料：BM25：Elasticsearch similarity settings: BM25

53. 什么查询会暴露纯向量召回的不足，为什么考虑加入关键词召回？

题目 ID：Q-d85082238aa8 · 编辑难度：medium

相关主题的报道公司（非逐题归属）：长鑫存储

参考答案

精确编号、型号、姓名、错误码和少见术语容易暴露纯语义检索的盲点；关键词检索保留精确命中，向量检索补同义和概念匹配。是否混合要看查询分桶后的收益。

得分点

  • 控制分词与字段
  • 按相同语料和预算对照

追问：数字字符相差一位，如何避免误召回？

易错点：向量相似不等于事实或实体相同。

面经主题线索：INT-9e5f65a93e（B：曾定位公开原帖）；INT-6d396c411c（C：仅聚合线索）

答案机制资料：BM25：Elasticsearch similarity settings: BM25；RRF：Reciprocal rank fusion in hybrid search

54. 请从排序依据解释 BM25，并说明它在你的项目里解决了什么问题。

题目 ID：Q-259defb1c29f · 编辑难度：medium

相关主题的报道公司（非逐题归属）：拼多多、长鑫存储

参考答案

BM25 利用查询词匹配、逆文档频率、词频饱和与文档长度归一化排序。k1 控制词频饱和，b 控制长度归一化强度；参数要结合分词、字段和验证集调。

得分点

  • 说明为何适合专名/编号检索
  • 检查停用词与字段长度

追问：同一词重复多次，分数是否线性增加？

易错点：BM25 不是向量相似度，默认参数也不是最佳答案。

面经主题线索：INT-6d396c411c（C：仅聚合线索）；INT-a896abf415（C：仅聚合线索）

答案机制资料：BM25：Elasticsearch similarity settings: BM25

55. 融合稀疏与稠密召回结果时，如何解释 RRF 的选择及参数影响？

题目 ID：Q-2239cbb0dafd · 编辑难度：hard

相关主题的报道公司（非逐题归属）：九方智投、字节跳动

参考答案

RRF 对每个候选累加 1/(k+rank)，融合排名而不是直接相加不可比的分数。k 小时更偏重头部；还需设每路召回深度、去重与缺失处理，并用验证集选配置。

得分点

  • 区分平滑常数 k 与召回 Top-K
  • 用相关性和延迟一起选型

追问：一路召回深度远大于另一路会怎样？

易错点：60 是常见配置，不是数学上必然最优。

面经主题线索：INT-1c8ef39841（B：曾定位公开原帖）；INT-fef75911f3（C：仅聚合线索）

答案机制资料：RRF：Reciprocal rank fusion in hybrid search

56. 重排模型增加了延迟，怎样证明它带来的质量收益值得成本？

题目 ID：Q-41cc17b9984f · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动、长鑫存储

参考答案

固定第一阶段候选与最终上下文预算，对比无重排、不同重排器和候选规模的证据排序、回答正确率及尾延迟。按任务难度决定是否条件式启用。

得分点

  • 记录单位成功任务成本
  • 评估截断是否丢掉答案证据

追问：重排模型只见到局部文本会有什么问题？

易错点：检索指标提升不必然转化为最终业务提升。

57. Top-K 结果噪声较大时，如何区分问题来自切块、召回还是重排？

题目 ID：Q-013afac9507d · 编辑难度：hard

相关主题的报道公司（非逐题归属）：拼多多

参考答案

先检查正确证据是否存在且被正确解析，再看它是否进入召回候选，随后看融合/重排是否保留，最后检查生成引用。每层保存候选 ID、版本、分数与标签。

得分点

  • 逐层建立可复现失败集
  • 控制一次只改一个环节

追问：召回正确而回答错误时还应继续调 Top-K 吗？

易错点：不能看到回答差就一律扩大召回数量。

面经主题线索：INT-a896abf415（C：仅聚合线索）

答案机制资料：BM25：Elasticsearch similarity settings: BM25；RRF：Reciprocal rank fusion in hybrid search

59. 知识库文档被更新或删除后，如何让旧向量和旧引用失效？

题目 ID：Q-769da7221f1a · 编辑难度：hard

相关主题的报道公司（非逐题归属）：

参考答案

  • 旧引用标失效而不是静默指向新内容

追问：异步索引短暂不一致时返回什么？

易错点：只更新正文而不删旧向量会留下过期答案。

60. 父子文档索引针对什么检索痛点，如何验证是否改善回答？

题目 ID：Q-35b90828dec3 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

小子块利于精确匹配，命中后加载相应父块补足定义和上下文。限制父块扩展、去重并保留引用位置；相同预算下比较证据覆盖和回答质量。

得分点

  • 保持父子版本绑定
  • 避免一次扩展塞入整篇长文

追问：多个子块属于同一个父块怎样处理？

易错点：扩大上下文并不必然提高准确率。

面经主题线索：INT-bfd0fa0cf9（B：曾定位公开原帖）

61. 口语化、错别字和不完整意图会怎样影响召回，你准备如何诊断？

题目 ID：Q-41474d62bd7b · 编辑难度：medium

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

用真实输入建立错别字、同义口语、指代和歧义分桶，分别查看召回与答案变化。可做规范化、查询改写或多路检索，意图不明时优先澄清并保留原始查询。

得分点

  • 改写要防止实体和数值被改变
  • 将澄清成本计入评测

追问：用户短句“那个怎么办”如何检索？

易错点：不能把所有陌生查询都强行改写成已知意图。

62. 多租户向量检索如何做到用户隔离，并用测试证明不会串库？

题目 ID：Q-17ae171c362d · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

从可信身份导出 tenant/ACL，并在向量与全文检索、父块扩展、缓存和引用读取各层强制过滤。敏感场景可再做索引或资源隔离；测试伪造租户、缓存串读与权限撤销。

得分点

  • 不能接受模型自报租户
  • 记录负向测试与撤权传播

追问：跨租户同文档 ID 会不会命中同一缓存？

易错点：在模型回答后过滤文本，已经太晚。

面经主题线索：INT-340e4aa1be（C：仅聚合线索）

答案机制资料：MCPTOOLS：MCP tools；INJECTION：OWASP LLM01: Prompt Injection

63. 短查询与长文块的表示差异会造成什么问题，如何设计对照实验？

题目 ID：Q-0f613a472055 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：美团

参考答案

长块可能混合多个主题，短 query 的表示又缺少上下文；需遵守所选 embedding 的 query/document 编码约定。固定评测集比较块长、前缀/双塔设置和证据粒度。

得分点

  • 先看模型是否支持非对称编码
  • 测召回再测最终答案

追问：改写查询能否解决所有长短差异？

易错点：不同模型的向量不能直接混在同一索引中比较距离。
