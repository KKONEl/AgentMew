📌 快手 AI Agent 开发二面

来源: 牛客网 2025-03-21

面试问题（8 道 + 手撕）： 1. 做 RAG 项目的时候，是怎么评测效果的？有哪些评测维度，具体用到了哪些指标？ 2. 项目里的数据集包含什么内容，数据来源、数据格式是怎样的？ 3. 如果让你对 RAG 的相关度和回答效果做优化，有什么思路？有没有更体系化的优化方案？ 4. 有一千条数据需要做求和处理，这种数据处理场景怎么设计实现？ 5. RAG 的性能怎么提升（工程层面或算法层面）？ 6. 项目里的上下文是怎么处理的？上下文过长、冗余等问题有什么优化方向？ 7. Agent 的长记忆和短记忆之间，怎么做到协同工作的？两者的衔接逻辑是什么？ 8. 有什么思路能让自己做的 Agent 更智能？

📌 携程 AI Agent 开发二面

来源: 牛客网 2025-03-23

💡 关键观察

当前 Agent 岗位已不限于大厂，携程、快手、比心等公司都在招。面试核心一致： - RAG 全链路是必考 - Agent 记忆机制是高频难点 - 项目实操能力比理论更重要
