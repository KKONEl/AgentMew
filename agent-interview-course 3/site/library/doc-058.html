67. 怎样构建覆盖工具失败、长任务和异常输入的 Agent 端到端评测集？

题目 ID：Q-5ea0a6e35c08 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

从任务契约拆目标、工具、权限、轮数及依赖，再分层采样真实任务与故障注入。冻结输入、来源和环境，分别标最终验收、过程约束及可接受部分成功。

得分点

  • 覆盖超时、未知副作用、取消、恢复与恶意输入
  • 报告分桶指标

追问：怎样防止测试环境比线上过于简单？

易错点：只有正常 happy path 的高分不能证明可靠性。

面经主题线索：INT-2bfa666e65（B：曾定位公开原帖）；INT-340e4aa1be（C：仅聚合线索）

答案机制资料：STATE：LangGraph persistence；INJECTION：OWASP LLM01: Prompt Injection

68. 用模型合成测试问题时，如何检查事实依据、质量与场景覆盖？

题目 ID：Q-372a9f181da7 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

先给生成器可核验材料和明确场景约束，再检查问题能否从证据回答、答案引用是否成立；做去重、难度与覆盖检查，抽样人工复核，训练和测试按来源分离。

得分点

  • 加入无答案与冲突样本
  • 别让同一模型独自出题、作答又给分

追问：合成数据风格太单一如何发现？

易错点：合成数量多不等于覆盖真实用户分布。

面经主题线索：INT-1c8ef39841（B：曾定位公开原帖）

答案机制资料：未单列外部机制资料，属于编辑推导，须结合具体契约独立验证。

69. 更换能力更强的模型后任务成功率下降，你会怎样分层归因？

题目 ID：Q-5e9f7cd9b585 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：vivo

参考答案

固定任务、工具和其他配置，逐层比较路由、参数结构、动作顺序、上下文处理、工具结果与终止条件。检查新模型的提示适配和能力接口，采用配对回放与单因素替换。

得分点

  • 把回归定位到具体失败类型
  • 核对 token/预算限制

追问：如何区分模型随机性与稳定退化？

易错点：基准榜更强不保证在你的运行时契约下更强。

面经主题线索：INT-4aea8e37ae（B：曾定位公开原帖）

答案机制资料：GRAPH：LangGraph: Workflows and agents；MCPTOOLS：MCP tools

70. 如何将线上对话 Trace 转成可重复执行、可人工复核的回归样本？

题目 ID：Q-497eab9e63c7 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：作业帮

参考答案

先脱敏并取得适当使用依据，保存输入、版本、必要状态及工具回执。回归时用可控桩或隔离环境重放，单独标识未重现的动态外部依赖；将失败和人工修复转成断言。

得分点

  • 冻结时间和随机性
  • 防止重放触发真实付费或写操作

追问：真实工具结果包含个人信息怎么办？

易错点：“重放线上 trace”不应等于再次执行线上副作用。

面经主题线索：INT-aa5fb6e122（C：仅聚合线索）

答案机制资料：REPLAY：LangGraph Graph API: re-execution and idempotency

71. 规则评分、模型评审与人工 Review 如何组合，避免评分互相矛盾？

题目 ID：Q-129cf8ceef60 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：作业帮

参考答案

确定性规则负责格式、权限和数值约束，模型评审负责开放语义，人工复核高风险与争议项。用有标签样本校准评分一致性，保留原始结果、评审版本和分歧，而非简单平均。

得分点

  • 模型评审先测偏差与稳定性
  • 必要时盲评和多次采样

追问：评审模型偏爱自己的回答怎么办？

易错点：模型评分高不等于业务事实正确。

面经主题线索：INT-aa5fb6e122（C：仅聚合线索）

答案机制资料：RAGAS：Ragas evaluation error handling and NaN results

72. RAG 评测指标出现 NaN 时，你会检查哪些输入和计算环节？

题目 ID：Q-8f71e2fe577e · 编辑难度：hard

相关主题的报道公司（非逐题归属）：

参考答案

区分数据校验错误与指标执行失败：检查指标所需列、类型、空上下文、参考答案和 judge 输出，再看超时、限流及解析异常。evaluate 的失败行可返回 NaN；缺少必需列也可能直接抛错。

得分点

  • 报告有效/无效样本分母
  • 诊断时显式暴露异常并记录版本

追问：把 NaN 当 0 或直接丢弃会带来什么偏差？

易错点：不能断言所有 NaN 都来自空参考答案，也不要悄悄忽略失败行。

面经主题线索：INT-9e5f65a93e（B：曾定位公开原帖）

答案机制资料：RAGAS：Ragas evaluation error handling and NaN results

73. 除了业务准确率，Agent 上线后还需要观察哪些质量和运行指标？

题目 ID：Q-58b176c3d714 · 编辑难度：medium

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

除最终成功率，还看违规/越权、错误引用、工具失败与未知结果、恢复/取消表现、端到端尾延迟、每个成功任务成本及人工接管率。按场景、版本和租户聚合，防止平均值掩盖风险。

得分点

  • 分清模型错误与工具/平台错误
  • 给告警配业务影响

追问：成功率升高但人工接管也升高意味着什么？

易错点：不能用模型调用次数或运行时长充当完成质量。

面经主题线索：INT-340e4aa1be（C：仅聚合线索）

74. 如何排除模型升级与测试集泄漏，验证收益确实来自运行时设计？

题目 ID：Q-c59ef9c2b2be · 编辑难度：hard

相关主题的报道公司（非逐题归属）：vivo

参考答案

固定模型、工具、数据和预算作运行时消融，再单独评估模型升级；按文档/时间/实体划分测试集，防止近重复与人工调参泄漏。报告多次运行的方差及失败样本。

得分点

  • 保留独立冻结测试集
  • 让验收检查尽量独立于被测 Agent

追问：既换框架又换模型的结果能说明什么？

易错点：一张总分表不能区分收益来自哪个变量。

面经主题线索：INT-4aea8e37ae（B：曾定位公开原帖）

75. 简历写“准确率由七成升至接近九成”，如何交代分母、样本和评测流程？

题目 ID：Q-e5f018ee87c9 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：美团

参考答案

交代任务定义、样本来源和数量、成功判据、标注方式及同一分母；尽量同样本配对比较并报告分桶、区间和无效样本。区分百分点提升与相对增幅。

得分点

  • 说明离线与线上差距
  • 数据不足时明确标为探索性结果

追问：任务难度分布变了还能直接比较吗？

易错点：不要把少量手挑样本的得分写成全量线上准确率。

面经主题线索：INT-0f90bd85b5（C：仅聚合线索）

76. 评测集没有覆盖某些真实场景时，如何发现缺口并安排后续补齐？

题目 ID：Q-00629102084b · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

通过线上未覆盖意图、工具组合、长尾错误与人工接管聚类发现缺口；按频率、风险和影响排序补样本，加入持续回归并定期重采样。保留冻结集评估，避免不停改测试来追分。

得分点

  • 负面和跨版本场景优先
  • 记录覆盖矩阵和新增原因

追问：低频但高损失场景如何排优先级？

易错点：没有失败样本不代表该场景已充分覆盖。

77. 如何在评测成本有限时批量检查 Skill 是否按预期完成任务？

题目 ID：Q-cea408f24ba2 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：快手

参考答案

用便宜规则先查契约、权限和产物，再对困难样本或抽样调用模型评审，人工查争议与高风险。按版本缓存可复用评分；小模型筛选也需测漏检率。

得分点

  • 覆盖 Skill 触发、执行和结果
  • 报告评分成本及置信度

易错点：不能只用文档相似度判断 Skill 执行正确。

78. 如果让你构建自动生成测试用例的 Agent，会怎样定义验收和质量门槛？

题目 ID：Q-ced565599ed3 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：百度

参考答案

输入应包括需求、接口契约和已有用例，输出用例需可执行、有合理断言并可追溯需求。隔离环境运行，检查重复、有效性、边界覆盖与缺陷检出能力，必要时用变异测试辅助。

得分点

  • 禁止把生成用例数量当质量
  • 控制测试资源和副作用

追问：一个生成的用例通过了，如何证明它有检测能力？

易错点：让同一 Agent 改实现直到自己生成的测试全过，会造成自证偏差。

面经主题线索：INT-1795ef9456（C：仅聚合线索）
