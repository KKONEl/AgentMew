37. 构造一次模型输入时，系统约束、用户消息、状态和工具结果如何分层？

题目 ID：Q-2078f8263d29 · 编辑难度：medium

相关主题的报道公司（非逐题归属）：字节跳动、海康威视

参考答案

将受信系统规则、当前用户请求、结构化任务状态、必要历史和工具观察分层；外部材料明确标成不受信数据。保证工具调用与结果按 ID 关联，并按依赖顺序组织。

得分点

  • 预留生成预算
  • 权限与用户身份来自运行时

追问：工具结果中出现“忽略前文”如何处理？

易错点：不能把检索内容拼成系统指令来提升“权威性”。

面经主题线索：INT-2bfa666e65（B：曾定位公开原帖）；INT-e363eb73e2（B：曾定位公开原帖）

答案机制资料：INJECTION：OWASP LLM01: Prompt Injection；MCPTOOLS：MCP tools

38. 工具一次返回几十兆数据时，如何在进入模型上下文之前完成处理？

题目 ID：Q-f72ae32dc22e · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

在工具边界限流、限体积，把原始内容存为有权限和生命周期的产物；返回大小、schema、统计摘要与引用。按需过滤、分页、采样或通过受控计算工具提取相关字段。

得分点

  • 输入模型前做字节和 token 预算
  • 摘要可回链到原数据

追问：用户后来需要摘要里没保留的细节怎么办？

易错点：先把几十兆拼进提示词，再要求模型摘要，已经太晚。

面经主题线索：INT-2bfa666e65（B：曾定位公开原帖）

答案机制资料：STATE：LangGraph persistence

39. 对话轮数不断增长时，如何控制上下文预算而不破坏任务连续性？

题目 ID：Q-28a3c147731d · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

固定保留目标、约束与当前状态，近期对话用滑窗，旧历史用可追溯摘要，长期事实按需检索；在输入前按 token 计费口径估算并留出输出空间。记录压缩版本及回放表现。

得分点

  • 不要丢失工具调用配对
  • 为高价值原文保留可恢复引用

追问：摘要累积误差怎么发现？

易错点：只按消息条数截断会忽略单条超大消息。

面经主题线索：INT-2bfa666e65（B：曾定位公开原帖）；INT-c233db2a53（B：曾定位公开原帖）

答案机制资料：STATE：LangGraph persistence

40. 如何验证压缩后的上下文仍保留决定下一步行动的关键信息？

题目 ID：Q-53d7a3257c5f · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

先定义必须保留的字段与事实，例如资源 ID、承诺、否定约束、未完成动作和审批范围；比较压缩前后在同一任务上的下一步决策及最终验收，必要时检索原文补回。

得分点

  • 字段检查加任务级回放
  • 加入长对话和冲突信息

追问：两份摘要文字不同但行动相同，如何评分？

易错点：不能只让同一个模型说“压缩得很好”就算验证。

面经主题线索：INT-52d6d4862a（B：曾定位公开原帖）；INT-332a893cbf（B：曾定位公开原帖）

答案机制资料：STATE：LangGraph persistence

41. 当前任务上下文与长期记忆的边界是什么，哪些内容不值得长期保存？

题目 ID：Q-7b3cf0a75a45 · 编辑难度：medium

相关主题的报道公司（非逐题归属）：字节跳动、网易

参考答案

上下文是当前决策可用的临时工作集；长期记忆保存跨任务仍有价值且有来源、权限和时效的事实。瞬时错误、未经证实推断、秘密以及无保留依据的信息不宜直接永久保存。

得分点

  • 记忆与知识库用途分离
  • 支持更新、过期与删除

追问：怎样决定一条信息是否有跨任务价值？

易错点：长期记忆不是聊天日志无限复制。

面经主题线索：INT-c233db2a53（B：曾定位公开原帖）；INT-6784717d92（C：仅聚合线索）

答案机制资料：STATE：LangGraph persistence

42. 工作记忆、短期记忆和长期记忆分别应保存什么信息？

题目 ID：Q-3389876d4408 · 编辑难度：medium

相关主题的报道公司（非逐题归属）：网易

参考答案

工作记忆保存当前计划、变量和中间结果；短期记忆保存一次会话或任务的近期交互；长期记忆保存经确认的稳定偏好与跨任务经验。三层是设计概念，不是必须采用三套数据库。

得分点

  • 分别定义生命周期和读取范围
  • 给每条事实附来源

追问：一次性行程地址是否适合长期保存？

易错点：不要把模型猜测当稳定用户事实。

面经主题线索：INT-6784717d92（C：仅聚合线索）；INT-02e3d8f7b6（B：曾定位公开原帖）

答案机制资料：STATE：LangGraph persistence

43. 同一用户出现互相矛盾的偏好或身份信息时，如何更新记忆？

题目 ID：Q-1b174081d135 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：网易、迅雷

参考答案

把记忆作为有来源、时间、适用范围和置信度的断言，而不是一个盲目覆盖的字符串。区分偏好改变、事实冲突与身份风险；高风险冲突需确认，旧记录保留版本或失效标记。

得分点

  • 权威来源优先但不能只看最新
  • 更新相关派生记忆

追问：同名用户是否被错误合并？

易错点：不能按最后一次模型输出就覆盖身份信息。

面经主题线索：INT-e123cde6cf（B：曾定位公开原帖）；INT-02e3d8f7b6（B：曾定位公开原帖）

答案机制资料：STATE：LangGraph persistence

44. 错误的用户姓名进入长期记忆后，怎样识别污染并修复历史影响？

题目 ID：Q-c73e0eb5e080 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：网易

参考答案

从错误回答追溯具体记忆及其来源，暂停该条参与检索，核验后更正或撤销，同时清理派生摘要、向量和缓存。按关联用户和任务检查影响范围，避免只修一处显示值。

得分点

  • 保留纠错审计和删除传播
  • 加身份隔离与写入验证

追问：原始聊天里仍有错误姓名，如何防止再次提取？

易错点：只改数据库中的姓名字段可能会被旧摘要重新污染。

面经主题线索：INT-02e3d8f7b6（B：曾定位公开原帖）

答案机制资料：STATE：LangGraph persistence

45. 主 Agent 与子 Agent 之间如何传递必要信息，又避免上下文相互污染？

题目 ID：Q-34148136c0aa · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动、小米

参考答案

传递目标、约束、必需资料引用和明确输入输出契约，而不是复制整段父上下文。子 Agent 有独立状态与权限作用域，输出携带证据；共享信息经显式合并才能进入父状态。

得分点

  • 隔离租户和敏感字段
  • 子结论不自动升级为权威事实

追问：子 Agent 需要更多上下文时怎么办？

易错点：逻辑上的角色不同，不代表存储和工具权限已经隔离。

面经主题线索：INT-bfd0fa0cf9（B：曾定位公开原帖）；INT-17e29773f1（B：曾定位公开原帖）

答案机制资料：STATE：LangGraph persistence

46. 用户偏好异步写入记忆时，如何解释并控制读取到旧信息的问题？

题目 ID：Q-ac00c1a24bcd · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

在当前请求内可直接覆盖使用已确认的新偏好，异步持久化则携带版本和顺序号；后续读取比较版本，必要时等待写入或返回一致性提示。过时写任务不能覆盖更新值。

得分点

  • 区分会话一致性与全局最终一致性
  • 写入幂等且可追踪

追问：异步队列乱序或重放怎样处理？

易错点：不能用“最终一致”掩盖永远不收敛的旧值覆盖。

面经主题线索：INT-2bfa666e65（B：曾定位公开原帖）

答案机制资料：STATE：LangGraph persistence

47. 上下文压缩时，哪些类型的信息应优先保全，怎样设计验证用例？

题目 ID：Q-0c03e1cb116f · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动、百度

参考答案

优先保全目标、权限限制、用户承诺、关键实体/数值、当前步骤、失败原因和未完成外部动作。把它们结构化并附来源，测否定指令、相似实体、跨轮改口及恢复场景。

得分点

  • 保留原文引用供按需回读
  • 业务状态不只存在摘要中

追问：压缩时如何处理过期审批？

易错点：压缩只能降低信息成本，不能保证无损。

面经主题线索：INT-c233db2a53（B：曾定位公开原帖）；INT-15d1d6b299（B：曾定位公开原帖）

答案机制资料：STATE：LangGraph persistence

48. 父子 Agent 的上下文已很长时，如何减少传递开销并说明信息损失边界？

题目 ID：Q-d609dc25c7c3 · 编辑难度：hard

相关主题的报道公司（非逐题归属）：字节跳动

参考答案

先让父层提供有界任务包和内容寻址引用，子层按需要检索；子层回传结论、证据和未解问题，原始轨迹留在产物中。评测遗漏重要条件的概率与最终完成率。

得分点

  • 约束和资源 ID 不做模糊摘要
  • 只展开真正相关的材料

追问：引用不可访问或版本变化时如何处理？

易错点：“把所有东西总结一下”无法解释损失边界。

面经主题线索：INT-bfd0fa0cf9（B：曾定位公开原帖）

答案机制资料：STATE：LangGraph persistence
