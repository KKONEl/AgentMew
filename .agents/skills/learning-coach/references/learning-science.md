# 学习设计依据

仅维护时读取；这些研究支持教学方向，不保证特定用户的学习效果，也不能证明固定天数或分数门槛普适。核对日期：2026-09-29。

- [IES/WWC：Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)：支持间隔学习、已解例与解题练习交替、抽象与具体联系、解释性提问。落实为小型示范→补全→独立变式，而非对初学者一直追问。该指南对不同建议的证据评级并不相同。
- [AERO：Spacing and retrieval practice](https://www.edresearch.edu.au/guides-resources/practice-guides/spacing-and-retrieval-practice-guide-full-publication)：强调延迟回忆、适当挑战、及时纠正和多情境应用。落实为先作答后反馈、同日练习与跨日检验分开；复习不只是背原句。
- [OpenAI：Build skills](https://developers.openai.com/plugins/build/skills)：明确触发条件、输入输出、决策与停止位置，支持材料按需读取，测试该触发和不该触发的请求。落实为短入口、可观察回合边界、项目级触发和行为案例。

本 Skill 的 1/3/7/14/30 天、同日计数上限、两次卡住后换方法、mastered 门槛是便于执行的工程约定。可据用户负担和真实延迟表现调整，不宣称为经验证的最优参数。

用户指定的两种 Skill 的设计借鉴和本项目取舍见 [source-adaptation.md](source-adaptation.md)；它们是工作流参考，与学习科学证据分开。
